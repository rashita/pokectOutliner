# Pocket Outliner

Mac向けの小さなテキストアウトライナー。Tauri 2と素のHTML/CSS/JavaScriptで実装しています。UIフレームワーク、エディターライブラリ、Markdownパーサー、フロントエンドのビルドツールは使用していません。ネイティブのファイル選択にTauri公式のdialogプラグインを使っています。

## 起動

Node.js、Rust、Xcode Command Line Toolsが必要です。

```sh
npm install
npm run dev
```

```sh
npm test       # アウトラインモデルのテスト
npm run check # JavaScript構文とRustのコンパイル確認
npm run build # src-tauri/target/release/bundle/macos/Pocket Outliner.app
```

## 操作

| 操作 | キー |
| --- | --- |
| カーソルを前後の行へ移動 | ↑ / ↓ |
| 同じ階層に行を追加 | Enter |
| 子孫ごと階層を変更 | Tab / Shift+Tab |
| 子孫ごと前後の兄弟と入れ替え | Option+↑ / ↓ |
| カーソル行にズーム・アウトライン全体を表示（Viewメニュー） | Option+Command+→ / Option+Command+← |
| 折りたたみ・展開 | Command+↑ / Command+↓、左の三角をクリック |
| 元に戻す・やり直す | Command+Z / Shift+Command+Z |
| 新規ウィンドウ | Command+N |
| 開く（複数選択可・各ファイル別ウィンドウ） | Command+O |
| 保存・名前を付けて保存 | Command+S / Shift+Command+S |
| ウィンドウを閉じる | Command+W |
| 操作ガイド | Shift+Command+/ |

新規ウィンドウ、開く、保存、名前を付けて保存は「File」メニュー、操作ガイドは「Help」メニューからも実行できます。

「View」→「カラーモード」でMacのデフォルト、ライトモード、ダークモードを選べます。選択はすべてのウィンドウに適用され、次回起動時にも引き継がれます。

左端の点・三角をドラッグすると、移動先の行の前へ、その階層に合わせてブロックを移動します。Enterは子孫がある場合、その子孫の後に兄弟行を追加します。Shift+Tabまたは行頭のBackspaceで、項目とその子孫を元の親のブロックの直後へ移します。最上位の空行は、子孫がなければ行頭のBackspaceで削除されます。日本語IMEの変換確定Enterは行追加に使用しません。

## ファイル

- UTF-8のテキストが対象です。拡張子ではなく、先頭行が `-` で始まるかどうかでMarkdownを判定します。新規文書はテキスト形式です。
- Markdownは `- 項目` の箇条書きを対象にします。見出しなどの表示変換はまだ行いません。
- 行頭の半角スペース・全角スペース・タブをそれぞれ1階層と数えます。Markdownでも半角スペース2個なら2階層です。
- 変更していない行の記法、空行、UTF-8 BOM、LF/CRLF、末尾改行の有無を維持します。階層変更時は文書中から取得したインデント文字（なければ半角スペース）を使います。混在した改行コードは保存時に統一します。
- 保存時は同じディレクトリの一時ファイルを経由して置き換えます。外部変更を検出した場合は上書きせず、別名保存を案内します。
- 折りたたみ状態はTauriのアプリデータディレクトリ内の `folds` に保存します。行番号の誤適用を避けるため内容のハッシュ値を一緒に記録し、一致する場合だけ復元します。元ファイルには追加情報を書き込みません。
- 未保存で閉じると保存確認が出ます。同じファイルを再度開くと既存ウィンドウにフォーカスします。

## 構成と現在の範囲

`src/model.js` が形式判定・読み書きと木構造操作、`src/app.js` がUI、`src-tauri/src/main.rs` がファイル・ウィンドウ管理を担当します。将来のMarkdown拡張はモデルの読み書き部分から追加できます。

初版ではFinderの「このアプリケーションで開く」との関連付け、ファイル自体のドロップ、複数行選択、検索、文字コード変換、カーソル位置の復元は未対応です。ドラッグは単一ブロックの移動に対応します。
